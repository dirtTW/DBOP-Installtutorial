# Recommended modpacks

Add one Modrinth or CurseForge modpack URL per line. New entries are added to
the recommendations page automatically during the next site build. Modrinth
titles, descriptions, versions, and images are fetched automatically.

CurseForge does not expose public page metadata to the static build, so new
CurseForge entries use a title based on the URL and the site logo as a fallback
image. Add an indented `image:` URL under the link to provide a custom image:

```markdown
link:
- https://www.curseforge.com/minecraft/modpacks/example-pack
  image: https://media.forgecdn.net/avatars/example.png
```
